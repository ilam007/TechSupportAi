About This Project

What is TechSupAI?

TechSupAI is a beginner-level technical support assistant built to help users describe product issues clearly, receive verified troubleshooting steps for common problems, and escalate unresolved issues — without AI guesswork.

The assistant uses predefined logic to match issues against a verified knowledge base. If confidence is low, it tells you honestly rather than inventing an answer.
